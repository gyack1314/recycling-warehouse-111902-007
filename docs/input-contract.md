# 原始资料契约

所有机构、车辆、单据和设备均为本地合成，不来自新闻中的真实企业，也不声称新闻发生过这些事件。

inputs/jobs.json为已有SQL业务定义，日期由调用者绑定d，表名代表本尝试输入关系，不是全局“最新”的授权。daily读取同日raw_day；balance读取同日daily和上一日balance；turnover读取本日及前六日daily并采用本日balance。日期区间包含端点，依赖不能越过尚不存在的前置结果。opening是明确给定的9月30日初始余额，不默认其他日期为0。
raw_day的每个日分区独立有修订，actions中的replace_partition即使rows=[]仍声明该日完整为空，没声明的日期是缺分区。calendar只声明日是否封口，不代替raw_day到齐；日空分区仍应有可检查的零行产物。现场可从小范围开始运行，再增添日期。
同一作业/日/输入指纹是一次确定计算，SQL没有外部副作用。调度器如何表达尝试与发布由实现选择。输入补报发生在作业运行期间是合法操作，工作台必须能区分成功产物与仍可用于当前依赖的产物。

seed.json与同名Parquet保存相同的输入值，actions.json中的后续动作尚未处理。inventory.json只校验原件物理完整性，不是仓库目录或业务结论。所有后续仓表与接口均待开发，源码不规定其架构。

9月25日至30日的零明细为七日窗口的既有完整输入；9月30日opening作为balance的起算锚点，不继续向更早日期递归。SQL中的previous_balance绑定到明确的上一日balance或这个锚点；关系别名不固定产品文件路径。
